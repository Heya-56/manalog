# Sample documents

`sample-invoice-photo.jpg` is a **fictional** commercial invoice (companies marked "(demo)"), photographed-style: skewed, with a wharf stamp over the text, glare and a handwritten draft-entry note that still uses Fiji's old 15% VAT.

Use it to try the photo flow: open the voice console, tap the camera button, pick this file. With Bedrock enabled, ManaLog transcribes it with a strict JSON Schema, then pacific-customs-kit recomputes the charges and flags the VAT discrepancy (1,696.82 FJD written vs 1,414.02 FJD expected at 12.5%).
